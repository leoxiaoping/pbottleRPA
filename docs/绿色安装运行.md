# 小瓶RPA纯绿色安装和运行

小瓶RPA所有模块可以在电脑免安装直接运行，**不需要系统安装权限和管理员权限**。

不需要 Windows UAC 用户账户控制权限，让所有电脑都可以直接运行小瓶RPA。

## 小瓶RPA基座的纯绿色安装和运行

官网下载绿色安装包解压即可运行，下载zip包解压即可运行。

参考：https://rpa.pbottle.com/a-14019.html


## 小瓶RPAdemo示例的绿色运行

官网下载demo示例zip包解压即可运行。

参考：https://rpa.pbottle.com/a-14019.html


## 【重要】脚本引擎的绿色安全和运行

下载脚本引擎**zip包**解压成 node 或者 python。

https://www.pbottle.com/a-13943.html

二进制内容保存到基座根目录下 `/bin/node` 或者 `/bin/python` 即可。

⚠ 此功能仅小瓶RPA基座版本V2026.4.1以上版本支持。
